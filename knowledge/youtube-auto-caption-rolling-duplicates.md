# YouTube 自動生成字幕のローリング重複を除去する

## 何が起きるか

`youtube-transcript` skill の CLI が自動生成字幕（`source: automatic_caption`）を取得すると、segments が「ローリング表示」のまま出てくる。YouTube の自動字幕は画面上で 2 行を送りながら表示するため、cue ごとに「前の行 + 新しい行」が入り、さらに 1 行だけの中間 cue が交互に挟まる。

実例（日本語自動字幕、`track_ext: vtt`）:

```
{'start': 3.51, 'text': 'こんにちは。よたです。今回は先日'}
{'start': 3.52, 'text': 'こんにちは。よたです。今回は先日 ボストンまでですね、フライト12時間'}
{'start': 5.99, 'text': 'ボストンまでですね、フライト12時間'}
{'start': 6.00, 'text': 'ボストンまでですね、フライト12時間 14時間ながら検索マーケティングの世界'}
```

この `text` をそのまま連結すると、全文が約 3 倍に膨らみ、同じ文が 2〜3 回繰り返される読めないテキストになる。18 分の動画で 30,000 字近くになった（実際の内容は約 10,000 字）。

## 除去の仕方

cue 単位で dedupe してはいけない。cue 内部にも重複が含まれるため、**行単位**で処理する。日本語自動字幕では 2 行が**半角スペース 1 個**で連結されているので、それで split して「直前に出力した行と同一ならスキップ」する。

```python
lines = []
last = None
for s in segments:
    for part in [p for p in s['text'].split(' ') if p.strip()]:
        if part == last:
            continue
        last = part
        lines.append((s['start'], part))
```

`seen` の set で全体 dedupe をしてはいけない。同じフレーズが動画内で再登場したときに落ちる。**直前 1 行との比較**で足りる。

英語字幕は行内に空白が入るためこの split はそのまま使えない。行区切りが `\n` で来るケースもあるので、まず `segments[:8]` を確認してから区切り文字を決める。

## 読みやすい形にする

dedupe 後は 1 行ずつだと細かすぎるので、45 秒程度ごとにまとめてタイムスタンプ付きの段落にすると、要約や引用箇所の特定がしやすい。

## 自動字幕を扱うときの注意

自動認識のため固有名詞と英語表現の誤変換が多い。実際に遭遇した例:

| 字幕の表記 | 実際 |
|---|---|
| エレデモ / レレモ / LMO | LLMO |
| GO | GEO |
| 歌詞性 / 貸視性 / 過性性 | 可視性 |
| 最低書 | サイテーション (citation) |
| レジット | Reddit |
| 最後峰 | 最高峰 |
| 試場 | 市場 |
| アドリビューション | アトリビューション |

文脈から明らかなものは補正してよいが、**数値・社名・登壇者名・セッションタイトルは補正の確信度が低い**。補正したもの / できなかったものを成果物に明記し、一次ソース確認を次アクションとして残す。
